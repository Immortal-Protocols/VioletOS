# QEMU emulator

The [QEMU launcher](../../tools/run.py) boots seL4 and connects the guest framebuffer and input to the desktop viewer. Run `make emulator` to use Home and Settings with the mouse. Use `make test-emulator` and `make test-isolation` to check touch, the watchdog and access boundaries.

Tests that tap apps find their icons with [home_grid.py](home_grid.py). [open-test-apps](open-test-apps) holds the test programs (Rust, C, Go, Python and the Sounds app) that `make test-open` and `make test-audio` build into their image. [test_system.py](test_system.py) (`make test-system`) is the one end-to-end test of the local loop, for what needs the real kernel, MMU or boot path; it uses [abi-test-apps](abi-test-apps), [wx-test-apps](wx-test-apps) and [policy-test-apps](policy-test-apps). Everything else belongs in the host [integration tests](../../tests/integration/README.md); [docs/test-map.md](../../docs/test-map.md) says where the earlier QEMU suites' assertions went. The main [README](../../README.md) lists the other test commands.
